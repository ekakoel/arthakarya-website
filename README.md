# Artha Karya Digital Website

Static SEO-optimized website for https://www.arthakaryadigital.com

## Deploy
Hostinger Git Deployment from branch `main`.

## Structure
- `id/` Indonesian pages
- `en/` English pages
- `assets/` CSS, JS, images
- `_pipeline/` Article publish SOP and template

## Automations (Grok)
1. **AKD Insights Artikel SEO 2 Mingguan** — draft artikel + image briefs
2. **AKD Publish Artikel Package** — package HTML + sitemap after approval

Owner reviews drafts; approved content is committed here then deployed via Hostinger Git.
